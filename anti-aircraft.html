Anti-Aircraft Defence System

This project focuses on the modeling and control of an automated 1:1 scale Anti-Aircraft Defense System (AADS) turret, based on the OTO 76/62 SR naval platform. Designed to track agile targets like the MQ-9 Reaper UAV at ranges up to 5000m, the plant was modeled as a 2-DOF serial mechanism using Euler-Lagrange dynamics coupled with a Stribeck friction model. I synthesized a bandwidth-separated cascaded control architecture integrated with a 9-state Extended Kalman Filter (EKF) for precise trajectory lead prediction. The end-to-end perception pipeline fuses a K-band MESA radar, LWIR thermal sensors, and an RGB camera running a YOLO object detector (79.3% precision), all validated within an NVIDIA Isaac Sim virtual war scenario.

Tools and Technologies

  • Simulation & Control: MATLAB, Simulink, Simscape Multibody, NVIDIA Isaac Sim
  • Computer Vision: Python, YOLOv8
